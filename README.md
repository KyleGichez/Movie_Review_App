### Overview
This is a software program built in flask. It enables user's to review movies and recommend the most favorite movies to all other users. Let's have a look ⏩

### Installation
To install this flask application, clone this repository into your local working environment.
````clone repository
git clone  https://github.com/KyleGichez/Movie_Review_App.git
````
Also, you can choose to download this project to your local working environment as a zip folder when you click the green code button in this repository.

### Requirements

To check all the dependencies installed when building this project, download the requirements.txt file.
````requirements.txt file
click==8.1.3
````
